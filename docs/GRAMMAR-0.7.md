# v0.7 문법 개선

이전 문법을 유지하면서 자주 쓰는 표현을 추가했습니다. C#/Unity API 이름과 복잡한 식은 기존 표기를 사용합니다.

## 함수 반환형 생략

반환값이 없으면 `은 없음` 또는 `는 없음`을 생략합니다. 멤버 함수와 지역 함수에서 모두 사용할 수 있습니다.

```text
공개 함수 인사():
    출력 "안녕하세요".
함수 끝.

공개 함수 더하기(정수 a, 정수 b)는 정수:
    반환 a + b.
함수 끝.
```

기존 `공개 함수 인사()는 없음:`과 `끝.`도 계속 지원합니다. 생략은 `void`이며 반환 자료형을 추론하지 않습니다. `async void`와 `async Task`는 다르므로 비동기 함수의 반환형을 의도에 맞게 명시하세요.

## 자연스러운 반복문

```text
정수 체력은 3이다.
체력이 0보다 큰 동안:
    출력 체력.
    체력에서 1을 뺀다.
반복 끝.

3번 반복:
    출력 "반복".
반복 끝.
```

동안 비교는 `큰`, `작은`, `크거나 같은`, `작거나 같은`, `같은`, `다른`을 지원합니다. 예: `값이 0과 다른 동안:`. 논리식은 `활성인 동안:` 또는 `체력 > 0 && 활성인 동안:`처럼 작성합니다. 조건은 매 반복마다 평가합니다. 기존 `동안 체력이 0보다 크면:`도 사용할 수 있습니다.

`3번 반복:`은 번호가 필요 없는 경우입니다. 0부터 2147483647까지의 정수 리터럴을 사용합니다. 음수·소수·범위 밖의 수는 허용하지 않습니다. 0번은 실행하지 않습니다. 내부 변수 이름은 원본과 충돌하지 않도록 생성합니다. 반복 번호나 식으로 계산한 횟수가 필요하면 기존 `반복 차례는 횟수회:`를 사용하세요. 큰 횟수는 Unity 메인 스레드를 오래 점유할 수 있습니다.

## 참·거짓

```text
논리 활성은 참이다.
활성에 거짓을 넣는다.
만약 활성 == 참이면:
    출력 "활성".
조건 끝.
```

한씨의 변수·필드 초기값, 속성 식, 조건·실행·반환 식에서 `참`과 `거짓`을 사용할 수 있습니다. 기존 `true`, `false`도 지원합니다. 문자열과 주석, `대상.참` 같은 멤버명, `@참` 같은 이스케이프 이름, C# 원문 블록은 바꾸지 않습니다. 특성 인수 등 C# 원문 표기 위치는 `true`/`false`를 사용하세요.

논리값을 출력할 때 문자열 표현은 C#의 `True`/`False`를 사용합니다.

이전 코드가 같은 파일에 `참` 또는 `거짓`이라는 변수·필드·매개변수·함수 등을 선언했다면 그 이름을 우선 보존합니다. 이 파일에서 논리 상수가 필요하면 `true`/`false`를 쓰세요. 다른 파일의 동명 심벌을 참조할 때는 `@참`/`@거짓` 또는 `대상.참`으로 구분하세요. 이는 프로젝트 전체 타입 분석 기능은 아닙니다.

## 짧은 실수형 별칭

```text
실수32 이동속도는 4f이다.
실수64 계산값은 1.5이다.
```

| 한씨 | C# |
|---|---|
| 실수32 / 단정도실수 | float |
| 실수64 / 실수 | double |

기존 `실수 = double`의 의미는 유지합니다. float의 소수 리터럴은 `4.0f`처럼 f를 붙입니다. 배열·제네릭·매개변수·반환형에도 별칭을 사용할 수 있습니다.

## 무엇을 닫는지 표시

| 표현 | 닫을 수 있는 블록 |
|---|---|
| 조건 끝. | 만약/아니면 |
| 반복 끝. | 동안/횟수 반복 |
| 함수 끝. | 지역 함수/멤버 함수 |
| 클래스 끝. | 클래스 |
| 이름공간 끝. | 이름공간 |
| 끝. | 가장 안쪽의 열린 블록 |

서로 섞어 쓸 수 있습니다. `조건 끝.`으로 함수를 닫으려 하면 잘못된 종료 행에서 오류를 알려줍니다. 여러 단계의 블록을 한 번에 닫지는 않습니다.

## 실행·자동완성·역변환

`app/HanCSharp.Cli.exe run samples/LanguageTour/Main.han`으로 전체 예제를 실행합니다. Visual Studio 자동완성에는 **논리 변수**, **간단 반복**, **동안 반복**, 새 별칭과 종료 표현을 추가했습니다. 확장을 **HanCSharp-0.7.vsix**로 업데이트하고 Visual Studio를 다시 여세요. VSIX 설치가 기존 확장을 갱신하며 같은 확장 ID를 사용합니다.

역변환은 반환형 없는 함수와 자연스러운 동안 표현, 함수·조건·반복의 종료 표현을 출력합니다. 실수형의 기존 명칭과 `true`/`false` 표기가 출력될 수도 있으며 모두 유효합니다. 공백·조사·별칭을 원래와 똑같이 복원하는 기능은 아닙니다.

Unity 프로젝트는 Editor 도구와 CLI를 같은 버전으로 갱신해야 합니다. 새 시작 창의 기본 Unity 예제는 버전별 새 경로에 준비하므로 이전 작업을 보존합니다. [업데이트 절차](UNITY-EDITING.md#기존-설치에서-업데이트)
