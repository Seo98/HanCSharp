# 처음 배우는 한씨 — 이름과 값을 먼저, 행동은 마지막에

바로 복사해서 실행하려면 **[대표 코드 예제 모음](CODE-EXAMPLES.md)**을 보세요. Hello World부터 Unity 이동·데미지까지 정리했습니다.

새 문법은 v0.9 작업본에서 사용할 수 있습니다. 처음에는 C#의 클래스·필드·반환형을 외울 필요가 없습니다. **무엇이 → 무엇을 → 어떻게 한다** 순서로 읽습니다. 주어가 분명하면 생략할 수도 있습니다.

```text
컴퓨터는 "안녕!"을 출력한다.
```

`컴퓨터는`이 주어, `"안녕!"을`이 목적어, `출력한다`가 행동입니다. 출력은 콘솔에 글을 한 줄 남기는 것입니다. Unity의 게임 화면에 글자 UI를 만드는 기능은 아닙니다.

## 1. 이름표가 붙은 상자 만들기

```text
체력은 100이다.
이름은 "민수"이다.
준비는 참이다.
```

체력이라는 상자에 100을 처음 넣습니다. 글자는 큰따옴표로 감싸고, 참·거짓은 따옴표 없이 씁니다. 값의 종류는 자동으로 정합니다. 이름에는 공백을 넣지 않습니다. `이동속도`, `남은사과`처럼 역할이 드러나는 이름이 좋습니다. 같은 범위에서 같은 이름을 두 번 만들지 마세요.

이미 만든 상자의 값을 바꿀 때는 이렇게 씁니다.

```text
체력에 80을 넣는다.
체력에 10을 더한다.
체력에서 5를 뺀다.
체력에 2를 곱한다.
컴퓨터는 체력을 출력한다.
```

결과는 170입니다. 계산에는 `+`, `-`, `*`, `/`, 괄호를 사용할 수 있습니다. 정수끼리 나누면 소수 부분이 버려집니다. `5.0 / 2`처럼 쓰면 2.5가 됩니다.

종류를 꼭 정하고 싶을 때만 길게 적습니다.

```text
체력은 정수이며 처음에는 100이다.
별명은 문자열이며 처음에는 "용사"이다.
```

`정수`는 소수점 없는 수, `문자열`은 글자의 모음입니다. 같은 상자의 종류를 중간에 바꾸지는 못합니다.

## 2. 그럴 때만 하기

```text
체력이 0보다 크다면:
    컴퓨터는 "움직이자!"를 출력한다.
아니라면:
    컴퓨터는 "쉬어야 해!"를 출력한다.
조건 끝.
```

조건을 만족하면 첫 번째 일을 하고, 만족하지 않으면 아니라면 아래의 일을 합니다. `아니라면:`은 필요 없으면 생략합니다.

| 하고 싶은 비교 | 작성 방법 |
|---|---|
| 더 큼 / 더 작음 | `체력이 0보다 크다면:` / `체력이 10보다 작다면:` |
| 이상 / 이하 | `체력이 10 이상이라면:` / `체력이 0 이하라면:` |
| 같음 / 다름 | `체력이 10이라면:` / `체력이 10과 다르다면:` |
| 참인지 확인 | `준비가 참이라면:` |

## 3. 같은 일 되풀이하기

```text
3번 되풀이한다:
    컴퓨터는 "할 수 있어!"를 출력한다.
되풀이 끝.
```

이 문장은 안쪽의 일을 세 번 합니다. 첫 버전의 간단 횟수는 `3`처럼 0 이상의 정수로 직접 적습니다. `되풀이를 멈춘다.`는 현재 되풀이를 끝내고, `다음 차례로 넘어간다.`는 남은 일을 건너뛰고 다음 차례를 시작합니다. 이 두 문장은 되풀이 안에서 씁니다.

조건이 유지될 때만 되풀이할 수도 있습니다.

```text
체력은 3이다.
체력이 0보다 큰 동안:
    컴퓨터는 체력을 출력한다.
    체력에서 1을 뺀다.
되풀이 끝.
```

3, 2, 1이 출력됩니다. 안에서 체력을 줄이지 않으면 끝없이 계속될 수 있습니다.

## 4. 여러 일에 이름 붙이기

```text
인사하기는 이렇게 한다:
    컴퓨터는 "안녕!"을 출력한다.
    컴퓨터는 "만나서 반가워!"를 출력한다.
동작 끝.

인사하기를 실행한다.
```

동작을 만드는 것과 실행하는 것은 다릅니다. 이름을 붙인 뒤 `인사하기를 실행한다.`로 불러야 실제로 인사합니다. 초급 동작에는 인수를 받거나 값을 돌려주는 기능을 넣지 않았습니다. 그 기능이 필요하면 기존 함수 문법과 함께 쓸 수 있습니다.

## 5. Unity에서 물체 움직이기

아래 원본의 파일 이름은 **HanEasyMover.han**입니다.

```text
HanEasyMover는 유니티 부품이다:
    조절할 이동속도는 4이다.

    처음 시작할 때:
        이 물체는 "출발!"을 기록한다.
    동작 끝.

    매 순간:
        이 물체는 오른쪽으로 초당 이동속도만큼 움직인다.
    동작 끝.
부품 끝.
```

1. [설치 안내](UNITYPACKAGE-INSTALL.md)대로 해당 문법이 포함된 v0.9 작업 패키지를 가져오고 검사·적용합니다. 기존 공개 v0.8 변환기는 새 문법을 모릅니다.
2. 예제 설치가 켜져 있다면 `Assets/HanCSharp/Examples/HanEasyMover.han`이 생깁니다.
3. Cube를 만들고 생성된 **HanEasyMover** 부품을 붙입니다.
4. Inspector의 **이동속도**를 4로 두고 Play를 누릅니다.

`처음 시작할 때:`는 Unity Start, `매 순간:`은 Update입니다. 이동 명령은 이미 프레임 시간을 곱합니다. **초당 4**이면 오른쪽으로 1초에 4 Unity 단위 움직입니다. 이 문장에 프레임 시간을 다시 곱하지 마세요. 방향은 세계 좌표 기준으로 오른쪽(+X)·왼쪽(-X)·위쪽(+Y)·아래쪽(-Y)·앞쪽(+Z)·뒤쪽(-Z)입니다. 회전 방향을 따라가는 로컬 이동이나 물리 충돌은 이 문장에 포함하지 않습니다.

`조절할`은 Inspector에서 바꿀 설정값입니다. 부품 바로 안에 둡니다. `4.5`처럼 소수도 쓸 수 있습니다. 계산식이나 다른 객체로 부품의 처음 값을 정할 때는 `값은 정수이며 처음에는 2 + 2이다.`처럼 종류도 적습니다. `이 물체는 ...를 기록한다.`는 Unity Console에 메시지를 남깁니다.

## 작성 약속과 자동완성

- 한 줄에 한 문장을 쓰고 마침표로 끝냅니다.
- 여러 일을 여는 줄에는 `:`을 붙이고 `조건 끝.`, `되풀이 끝.`, `동작 끝.`, `부품 끝.`으로 닫습니다. 간단한 `끝.`도 됩니다.
- 들여쓰기는 사람이 쉽게 읽기 위한 것입니다. 블록은 끝 문장으로 구분합니다.
- `은/는`, `이/가`, `을/를`은 모두 허용합니다. 처음에는 맞춤법보다 코드의 뜻에 집중해도 됩니다.
- `//` 뒤에는 설명을 쓸 수 있습니다.
- Visual Studio **HanCSharp-0.9.vsix** 설치 후 Ctrl+Space에서 **쉬운 값 만들기 / 쉬운 출력 / 쉬운 조건 / 쉬운 되풀이 / 쉬운 동작 만들기 / 쉬운 유니티 부품**을 선택하세요.

문법을 완전히 자유로운 한국어로 쓰는 기능은 아닙니다. 예를 들어 `오른쪽으로 가 줘!`를 임의로 해석하지 않고 안내된 문장 틀을 사용합니다. 기존 v0.7·v0.8 문법과 일반 C# API도 함께 사용할 수 있습니다. C#에서 한씨로 역변환한 결과는 기존 호환 문법으로 나올 수 있습니다.

콘솔 전체 예제는 `samples/Beginner/Main.han`, Unity 전체 예제는 `samples/UnityScripts/HanEasyMover.han`입니다. 소스를 빌드할 개발자는 저장소 루트에서 다음과 같이 실행합니다.

```powershell
dotnet run --project src/HanCSharp.Cli -- run samples/Beginner/Main.han
```
