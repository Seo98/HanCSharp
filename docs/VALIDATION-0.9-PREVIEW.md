# v0.9 초급 한국어 문법 작업본 검증

2026-11-10 / Windows x64 / Unity 6000.3.25f1. v0.9 소스와 로컬 작업 패키지의 검증 기록입니다. GitHub 소스에는 새 문법이 반영되어 있으며, 공개 패키지 릴리스는 v0.8입니다.

## 자동 검증

언어 42개, 편집 지원 15개, Unity 연결 모형 27개, 안전한 업데이트·저장 감지 16개, 기존 설치 준비 회귀 10개로 총 **110개 통과**했습니다. 기존 문법·C# 원문·논리값과 같은 이름·왕복 실행을 유지하면서 초급 선언/출력/조건/되풀이/동작/Unity 부품/오류 행을 추가 확인했습니다.

`samples/Beginner/Main.han` 실제 CLI 실행 결과:

```text
민수
아직 움직일 수 있어!
할 수 있어!
할 수 있어!
할 수 있어!
```

Visual Studio 확장 0.9.0은 경고 0·오류 0으로 빌드했습니다. 새 자동완성 틀은 실제 변환기와 C# 구문 검사로 검증했습니다. 실제 Visual Studio 프로필에 확장을 설치하거나 IME 조합을 다시 검증하지는 않았습니다.

## 실제 Unity

- 기존 v0.8 QA 프로젝트에서 v0.9 payload를 검사·백업 후 적용했습니다.
- 새 HanEasyMover.han이 C#으로 생성되고 Unity에서 컴파일 오류가 없음을 확인했습니다.
- Cube에 HanEasyMover를 붙이고 Inspector의 이동속도 기본값 4를 확인했습니다.
- 실제 Play에서 1.133892초 동안 세계 좌표 +X로 4.536단위 이동했습니다. 초당 4단위와 일치합니다.
- Play 중 SerializedObject로 Inspector 직렬화 값 이동속도를 2로 바꾸자 0.808178초 동안 +X로 1.616단위 이동했습니다. Y/Z 이동은 없었습니다.
- 검증 후 Play를 종료했습니다. QA 씬과 검증 스크립트는 제품 패키지에 포함하지 않았습니다.

## 파일

`HanCSharp-v0.9.0-preview.unitypackage`는 실제 Unity AssetDatabase.ExportPackage로 추출했습니다. EXE 대신 DLL payload와 설치 도구를 담으며 .NET Runtime은 사용자가 직접 설치합니다. 초급 문법 문서와 HanEasyMover 원본을 포함합니다. 선택 편집기 확장은 `HanCSharp-0.9.vsix`입니다.

첫 패키지 설치와 온라인 업데이트 기반 기능은 v0.8에서 검증했고, 이번에는 v0.8에서 v0.9로 적용하는 흐름과 새 문법 예제를 검증했습니다. 다른 운영체제, 다른 Unity 버전, Rigidbody 충돌 이동, 게임 화면 UI 출력은 이번 검증 범위가 아닙니다.
