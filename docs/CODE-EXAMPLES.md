# 한씨 대표 코드 예제

복사해서 따라 할 수 있는 **v0.9 문장형 문법** 예제입니다. 공개 v0.8 변환기는 새 문법을 지원하지 않으므로 v0.9 작업 패키지와 변환기를 사용하세요. 문법 설명은 [입문 가이드](BEGINNER-GUIDE.md), 설치는 [설치 가이드](UNITYPACKAGE-INSTALL.md)를 참고하세요.

각 코드 블록은 따로 실행하는 예제입니다. 같은 파일에 모두 붙이면 같은 이름의 값을 두 번 만드는 오류가 날 수 있습니다. `//` 뒤는 설명이며 실행되지 않습니다.

## 콘솔 예제 실행 방법

1~6번은 컴퓨터 콘솔에서 실행합니다. 각각 `.han` 파일로 저장하세요. 소스를 빌드할 수 있는 .NET SDK 환경에서는 저장소 루트에서 다음 명령을 실행합니다. `예제파일.han`은 실제 저장한 경로로 바꿉니다.

```powershell
dotnet run --project src/HanCSharp.Cli -- run 예제파일.han
```

Unity 패키지만 설치했다면 Unity 프로젝트 루트에서 설치된 DLL을 실행할 수도 있습니다. 이 경우 .NET Runtime만 있으면 됩니다.

```powershell
dotnet Tools/HanCSharp/HanCSharp.Cli.dll run 예제파일.han
```

콘솔 예제의 `컴퓨터는 ...을 출력한다.`는 터미널에 글을 씁니다. Unity에서는 7번의 `이 물체는 ...을 기록한다.`를 사용해 Unity Console에 표시하세요. 게임 화면의 글자 UI를 만드는 문장은 아닙니다.

## 1. 헬로 월드

파일 이름 예: `HelloWorld.han`

```han
컴퓨터는 "Hello, World!"를 출력한다.
컴퓨터는 "안녕, 한씨!"를 출력한다.
```

결과:

```text
Hello, World!
안녕, 한씨!
```

**컴퓨터는 → 인사말을 → 출력한다** 순서입니다. 글자는 큰따옴표로 감쌉니다.

## 2. 이름과 점수

파일 이름 예: `Score.han`

```han
이름은 "민수"이다.
점수는 0이다.

점수에 10을 더한다.
점수에 20을 더한다.

컴퓨터는 이름을 출력한다.
컴퓨터는 점수를 출력한다.
```

결과:

```text
민수
30
```

`점수는 0이다.`는 값을 처음 만듭니다. 이미 만든 값을 바꾸려면 `점수에 50을 넣는다.`처럼 씁니다.

## 3. 조건에 따라 다른 말 하기

파일 이름 예: `Condition.han`

```han
사과개수는 3이다.

사과개수가 0보다 크다면:
    컴퓨터는 "사과를 먹을 수 있어!"를 출력한다.
아니라면:
    컴퓨터는 "사과가 없어!"를 출력한다.
조건 끝.
```

결과는 `사과를 먹을 수 있어!`입니다. 첫 줄의 3을 0으로 바꾸면 `사과가 없어!`가 나옵니다.

## 4. 같은 일 세 번 하기

파일 이름 예: `Repeat.han`

```han
응원하기는 이렇게 한다:
    컴퓨터는 "할 수 있어!"를 출력한다.
동작 끝.

3번 되풀이한다:
    응원하기를 실행한다.
되풀이 끝.
```

결과:

```text
할 수 있어!
할 수 있어!
할 수 있어!
```

`응원하기는 이렇게 한다:`로 할 일에 이름을 붙이고, `응원하기를 실행한다.`로 부릅니다.

## 5. 데미지를 받고 쓰러지기

파일 이름 예: `Damage.han`

```han
체력은 100이다.
피해량은 30이다.

4번 되풀이한다:
    체력에서 피해량을 뺀다.

    체력이 0 이하라면:
        체력에 0을 넣는다.
    조건 끝.

    컴퓨터는 체력을 출력한다.

    체력이 0이라면:
        컴퓨터는 "쓰러졌습니다!"를 출력한다.
        되풀이를 멈춘다.
    조건 끝.
되풀이 끝.
```

결과:

```text
70
40
10
0
쓰러졌습니다!
```

한 번 맞을 때 30씩 줄고, 체력은 0 아래로 내려가지 않습니다. 체력이 0이면 현재 되풀이를 끝냅니다. 이 예제는 체력 계산 연습이며 충돌이나 공격 버튼을 자동으로 연결하지 않습니다.

## 6. 체력 회복하기

파일 이름 예: `Heal.han`

```han
최대체력은 100이다.
체력은 80이다.
회복량은 30이다.

체력에 회복량을 더한다.

체력이 최대체력보다 크다면:
    체력에 최대체력을 넣는다.
조건 끝.

컴퓨터는 체력을 출력한다.
```

결과는 `100`입니다. 80에 30을 더하면 110이지만 최대체력인 100에서 멈춥니다.

## Unity 예제 실행 방법

7~9번은 Unity 부품입니다. 다음 순서로 사용합니다.

1. v0.9 작업 패키지를 가져온 뒤 **Tools → HanCSharp → 설치 및 안전한 업데이트**에서 검사·적용합니다.
2. Project 창에서 **Create → HanCSharp → 한씨 컴포넌트**를 선택하고 아래에 적힌 이름으로 만듭니다.
3. `.han` 원본 내용을 예제 코드로 바꾸고 저장합니다. 파일 이름과 부품 이름을 똑같이 맞추세요.
4. Unity로 돌아와 컴파일을 기다립니다. 자동 생성이 꺼져 있다면 **Tools → HanCSharp → Generate All**을 누릅니다.
5. Cube 같은 물체에 생성된 부품을 붙이고 Play를 누릅니다.

각 예제는 별도로 시험하세요. 특히 같은 물체에 이동 예제를 여러 개 붙이면 이동량이 합쳐집니다.

## 7. Unity에서 인사하기

**파일 이름: `HanHelloWorld.han`**

```han
HanHelloWorld는 유니티 부품이다:
    처음 시작할 때:
        이 물체는 "Hello, World!"를 기록한다.
        이 물체는 "안녕, 유니티!"를 기록한다.
    동작 끝.
부품 끝.
```

물체에 **HanHelloWorld**를 붙이고 Play를 누르면 Unity Console에 두 인사가 나옵니다. `처음 시작할 때:`는 Unity의 Start이며 보통 이 부품이 실행을 시작할 때 한 번 호출됩니다. 부품과 물체가 활성 상태인지 확인하세요.

## 8. Unity에서 물체 움직이기

**파일 이름: `HanMoveExample.han`**

```han
HanMoveExample는 유니티 부품이다:
    조절할 이동속도는 4이다.

    매 순간:
        이 물체는 오른쪽으로 초당 이동속도만큼 움직인다.
    동작 끝.
부품 끝.
```

Cube에 **HanMoveExample**을 붙이면 세계 좌표의 오른쪽(+X)으로 초당 4 Unity 단위 움직입니다. Inspector의 **이동속도**를 2로 바꾸면 느려집니다. Play 중 바꾼 값은 Play를 끝내면 원래대로 돌아갑니다. 계속 쓸 값은 편집 모드에서 바꾸고 씬을 저장하세요.

방향 단어만 바꿀 수 있습니다.

| 방향 단어 | 세계 좌표 방향 |
|---|---|
| 오른쪽으로 / 왼쪽으로 | +X / -X |
| 위쪽으로 / 아래쪽으로 | +Y / -Y |
| 앞쪽으로 / 뒤쪽으로 | +Z / -Z |

`매 순간:`은 Update입니다. 이동 문장에 프레임 시간 계산이 이미 들어 있으므로 Time.deltaTime을 다시 곱하지 않습니다. Transform 이동이라 벽과의 충돌이나 Rigidbody 물리 이동은 처리하지 않습니다.

## 9. Unity에서 데미지 받기

**파일 이름: `HanDamageExample.han`**

이 예제부터는 기존 C# 연동 문법을 일부 함께 씁니다. 패키지의 예제 설치를 켜서 **HealthState.han**도 준비하세요. 체력을 계산하는 일반 클래스는 기존 HealthState가 담당하고, 아래 부품은 호출과 Unity Console 표시를 담당합니다.

```han
HanDamageExample는 유니티 부품이다:
    비공개 필드 HealthState _health는 new HealthState()이다.
    조절할 _damage는 30이다.

    처음 시작할 때:
        피해받기를 실행한다.
    동작 끝.

    피해받기는 이렇게 한다:
        _damage가 0 이하라면:
            여기서 마친다.
        조건 끝.

        _health.Current가 0 이하라면:
            여기서 마친다.
        조건 끝.

        _health.TakeDamage(_damage)를 실행한다.
        이 물체는 _health.Current를 기록한다.

        _health.Current가 0이라면:
            이 물체는 "쓰러졌습니다!"를 기록한다.
        조건 끝.
    동작 끝.
부품 끝.
```

Cube에 **HanDamageExample**을 붙이고 Inspector의 **Damage**를 30으로 둡니다. Play 시작 때 한 번 피해를 받아 Unity Console에 `70`이 나옵니다. 편집 모드에서 Damage를 100으로 바꾸고 다시 Play하면 `0`과 `쓰러졌습니다!`가 나옵니다. 0 이하의 피해량과 이미 쓰러진 상태의 호출은 무시합니다.

`피해받기는 이렇게 한다:`로 만든 부품의 동작은 공개 메서드입니다. 다른 C# 코드에서 이미 연결한 참조를 통해 호출할 수도 있습니다. 아래 코드는 Unity에 자동 연결되는 추가 부품이 아니라 호출 형태를 보여주는 한 줄입니다.

```csharp
damageExample.피해받기();
```

`damageExample`에는 Inspector 또는 초기화로 연결한 HanDamageExample 참조가 있어야 합니다. 실제 게임에서는 공격·충돌을 담당하는 코드가 이 동작을 호출하도록 연결합니다. 체력 UI나 충돌 판정은 이 예제에 포함하지 않습니다.

## 자주 생기는 실수

| 증상 | 확인할 것 |
|---|---|
| 새 문장을 모른다고 나옴 | 변환기가 v0.9 작업본인지 확인 |
| 같은 이름이 이미 있다고 나옴 | 독립 예제를 한 파일에 모두 붙이지 않았는지 확인 |
| Unity 부품이 안 붙음 | 파일명과 부품명 일치, Console 컴파일 오류 확인 |
| 한씨 파일만 있고 C#이 없음 | Auto Generate 또는 Generate All 확인 |
| Hello World가 Unity Console에 안 나옴 | Unity에서는 출력한다 대신 기록한다 사용, 부품 활성 여부 확인 |
| 데미지 예제에서 HealthState를 못 찾음 | 예제 설치를 켰는지, HealthState.han이 C#으로 생성됐는지 확인 |

## 예제 검증

1~6번은 문서의 코드를 그대로 추출해 실제 실행하고 위 예상 출력과 일치하는지 확인했습니다. 7~9번은 Unity 6000.3.25f1의 실제 참조 어셈블리로 컴파일 검사를 통과했습니다. 9번 검사에는 기존 HealthState도 함께 포함했습니다. 이번 문서 작업에서 세 Unity 예제의 에디터 Play를 별도로 실행하지는 않았습니다. 실제 키 입력·공격 충돌·게임 UI까지 구현한 완성 게임 예제와는 구분합니다.
